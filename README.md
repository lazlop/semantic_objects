# Semantic Objects Documentation

Welcome to the **Semantic Objects** library documentation! This library connects ontologies for the built environment (Brick, ASHRAE 223P, WATR) to the tools built on top of them, through a single Python class layer.

The `semantic_objects.s223` classes aren't hand-written - they're generated by ingesting the real ASHRAE 223P ontology's SHACL shapes (`src/semantic_objects/ingest/`, vendored ontology at `src/semantic_objects/ontologies/`). From that one generated layer, the library simplifies:
- Ingesting an ontology's SHACL shapes into typed Python classes
- Creating SHACL/Ontology statements for validation of existing semantic models or use in other tools
- Creation of templates to enable use of BuildingMOTIF or other resources for creating building models
- Loading of semantic models into python objects to simplify querying and metadata usage

Hand-written classes still have a place - they're the *override* layer for customization that can't be derived from SHACL (see `s223-generated-classes-tutorial.ipynb` and `ontology-ingestion-tutorial.ipynb`).

## 🎯 Key Features

### 1. **Ontology Ingestion**
Classes are generated from the real ontology's SHACL shapes, not hand-typed:

```python
# python -m semantic_objects.ingest.cli --ontology s223
# generates src/semantic_objects/s223/_generated/{entities,properties,enumerationkinds,relations}.py
from semantic_objects.s223 import entities
print(entities.DomainSpace.__dataclass_fields__)
```

### 2. **Automatic Query Generation**
Generate SPARQL queries automatically from class definitions:

```python
query = entities.DomainSpace.get_sparql_query(ontology='s223')
```

### 3. **Type-Safe Model Loading**
Load RDF data into typed Python objects:

```python
loader = ModelLoader(source="building.ttl")
spaces = loader.load_instances(entities.DomainSpace, ontology='s223')
```

### 4. **Template Generation**
Create BuildingMOTIF templates automatically:

```python
export_templates(entities.DomainSpace, 'templates/')
```

### 5. **SHACL Validation**
Generate SHACL shapes for validation:

```python
shacl_shape = entities.DomainSpace.generate_rdf_class_definition()
```

## 🚀 Quick Example

```python
from semantic_objects.s223 import entities, enumerationkinds
from semantic_objects.model_loader import ModelLoader

# Instantiate a real, ontology-generated class
zone = entities.DomainSpace(domain=enumerationkinds.HVAC())

# Load spaces from RDF graph
loader = ModelLoader(source="building.ttl")
spaces = loader.load_instances(entities.DomainSpace, ontology='s223')

# Generate templates
from semantic_objects.exporters import export_templates
export_templates(entities.DomainSpace, 'templates/')
```

## 🏗️ Architecture Overview

The library is built around four core concepts:

1. **Ontology Ingestion**: Parse an ontology's SHACL shapes into Python `Resource` classes (`src/semantic_objects/ingest/`)
2. **Generated + Override Classes**: Generated base classes (`s223/_generated/`) plus hand-written subclasses for customization not derivable from SHACL (`s223/entities.py`, `s223/properties.py`, ...)
3. **Model Loader**: Query RDF graphs and instantiate Python objects
4. **Template Generation**: Create BuildingMOTIF templates and SHACL shapes for model building
